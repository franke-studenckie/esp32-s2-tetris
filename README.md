# Tetris na ESP32-S2 z matrycą LED HUB75 (32x64) i sterowaniem Wi-Fi

Projekt gry Tetris realizowany na mikrokontrolerze ESP32-S2-DevKitC-1 z wyświetlaczem LED RGB HUB75 (64x32 pracującym w orientacji pionowej 32x64) oraz kontrolerem w formie aplikacji webowej na smartfonie.

## Status projektu
W trakcie realizacji (przygotowanie pod v0.1.0).
